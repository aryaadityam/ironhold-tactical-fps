IRONHOLD is a round-based tactical FPS built with three.js, in the structure Counter-Strike made famous and at a brisk Point Blank pace. Two bot teams fight over Sector 9, a dusk-lit industrial yard: GARUDA defends the crane power core while KOMODO attacks with a breaching charge. Short rounds, a buy phase with a full money economy, and gunplay where accuracy counts more than speed. Single-player against bots, fully offline from static files, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and click Deploy.
